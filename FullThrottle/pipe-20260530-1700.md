**Automação Nova para Criar**

Para esta semana, proposto criar uma nova automação para:

* **Envio de e-mails de boas-vindas personalizados** para novos clientes que realizam compras na loja Aura Decore.
* **Trigger:** Quando um novo cliente realiza uma compra e é criado um novo registro de cliente no Shopify.
* **Nodes:**
 + Node de envio de e-mail com template personalizado.
 + Node de busca de informações do cliente no Shopify.
 + Node de tratamento de erro para lidar com casos de falha no envio de e-mail.
* **Integrações:**
 + Integração com o Shopify para buscar informações do cliente.
 + Integração com o serviço de e-mail para enviar o e-mail de boas-vindas.
* **Tratamento de Erro:**
 + Implementar um node de tratamento de erro para lidar com casos de falha no envio de e-mail, como problemas de conectividade ou erro no template de e-mail.
* **JSON Resumido:**
 + Exemplo de JSON que será enviado para o serviço de e-mail:
```json
{
  "nome": "Nome do Cliente",
  "email": "email.do.cliente@exemplo.com",
  "mensagem": "Bem-vindo à Aura Decore! Obrigado por realizar uma compra conosco."
}
```
Essa automação ajudará a melhorar a experiência do cliente e aumentar a satisfação com a loja. Além disso, ajudará a reduzir o tempo de resposta dos agentes e melhorar a eficiência da equipe de atendimento ao cliente.
