# THEO · Tarefa Full Throttle

**Briefing:** Auditoria técnica diária Shopify: pixel, velocidade, produtos sem foto, links quebrados. Liste top 3 itens para corrigir hoje.

---

Com base nos dados disponíveis e considerando a fase de lançamento orgânico da loja Aura Decore, aqui estão os top 3 itens para corrigir hoje na auditoria técnica diária Shopify:

1. **Pixel Meta: Verificação de Instalação e Funcionamento**
 - **Motivo:** O pixel é crucial para o rastreamento de conversões e para a otimização de anúncios no Facebook e Instagram. Problemas na instalação ou funcionamento podem afetar a capacidade de coletar dados precisos sobre o comportamento dos usuários na loja.
 - **Ação:** Verificar se o pixel Meta está corretamente instalado no Shopify, se os eventos padrão (como compra, adição ao carrinho, etc.) estão configurados e se o pixel está enviando dados para a plataforma Meta. Utilizar a ferramenta de depuração do Pixel Meta para identificar e solucionar quaisquer problemas.

2. **Velocidade da Loja: Otimização de Imagens e Arquivos**
 - **Motivo:** A velocidade da loja é fundamental para a experiência do usuário e para o SEO. Imagens grandes e arquivos não otimizados podem aumentar significativamente o tempo de carregamento da página.
 - **Ação:** Identificar e otimizar todas as imagens dos produtos e da loja que estão acima de 100KB. Utilizar ferramentas como o TinyPNG ou o ImageOptim para reduzir o tamanho dos arquivos sem comprometer a qualidade. Além disso, verificar se há outros arquivos (como JavaScript e CSS) que possam ser minimizados ou combinados para reduzir o número de requisições ao servidor.

3. **Produtos Sem Foto: Adicionar Imagens de Alta Qualidade**
 - **Motivo:** Produtos sem fotos são menos prováveis de serem vendidos, pois os clientes precisam visualizar os produtos para tomar decisões de compra. Além disso, a falta de imagens pode afetar negativamente a experiência do usuário e a confiabilidade da loja.
 - **Ação:** Identificar todos os produtos que não têm fotos e adicionar imagens de alta qualidade para cada um. Certificar-se de que as imagens refletem a estética Japandi premium da loja Aura Decore e seguem as diretrizes de marca. Utilizar a funcionalidade de upload em massa do Shopify para agilizar o processo, se necessário.

Essas ações devem ser priorizadas para melhorar a performance da loja, a experiência do usuário e, em última análise, as conversões. Além disso, é recomendável monitorar as métricas no Windsor.ai para avaliar o impacto dessas correções
