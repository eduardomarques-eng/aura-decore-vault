**Briefing:** Auditoria técnica diária Shopify: pixel, velocidade, produtos sem foto, links quebrados. Liste top 3 itens para corrigir hoje.

---

Com base nos dados disponíveis e no contexto da loja Aura Decore, aqui estão os top 3 itens para corrigir hoje na auditoria técnica diária Shopify:

1. **Verificar o funcionamento do Pixel Meta**: 
   - Acesso ao Painel de Controle do Shopify e verifique se o Pixel Meta está configurado corretamente.
   - Utilize a ferramenta de depuração do Pixel Meta para identificar possíveis erros ou problemas de rastreamento.
   - Corrija quaisquer problemas encontrados para garantir que os eventos de conversão sejam rastreados corretamente.

2. **Optimizar a velocidade da loja**:
   - Utilize a ferramenta PageSpeed Insights para analisar a velocidade da loja e identificar áreas de melhoria.
   - Implemente otimizações de desempenho, como a compressão de imagens, minificação de arquivos CSS e JS, e uso de cache.
   - Verifique se as otimizações implementadas melhoraram a velocidade da loja e faça ajustes adicionais se necessário.

3. **Identificar e corrigir produtos sem foto**:
   - Acesso ao catálogo de produtos do Shopify e execute uma busca para encontrar produtos sem imagem.
   - Adicione imagens de alta qualidade para os produtos sem foto, garantindo que elas estejam de acordo com o estilo visual da loja Aura Decore.
   - Verifique se as imagens adicionadas estão carregando corretamente e se os produtos estão sendo exibidos corretamente na loja.

Esses itens devem ser priorizados para garantir que a loja Aura Decore forneça uma experiência de usuário ótima, melhore a conversão e aumente a visibilidade orgânica. Além disso, é importante monitorar as métricas de desempenho da loja por meio da API do Windsor.ai (GET /windsor/metrics) para identificar outras áreas de melhoria.
