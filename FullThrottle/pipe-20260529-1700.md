**Automação Nova para Criar**

Esta semana, pretendo criar uma nova automação para sincronizar os produtos do Shopify com o Pinterest. Isso permitirá que os produtos sejam publicados automaticamente no Pinterest quando forem criados ou atualizados no Shopify.

**Detalhes da Automação**

* Trigger: Novo produto criado ou atualizado no Shopify
* Nodes:
 + Shopify: Obter produto
 + Pinterest: Publicar produto
 + AppMax: Enviar notificação de publicação para o time de marketing
* Integrações:
 + Shopify API
 + Pinterest API
 + AppMax API
* Tratamento de Erro: Verificar se o produto foi publicado corretamente no Pinterest e enviar notificação de erro se necessário
* JSON Resumido: Será gerado um JSON com informações sobre o produto publicado, incluindo ID do produto, nome do produto, descrição do produto e URL do produto no Pinterest.

Essa automação ajudará a reduzir o tempo de publicação de produtos no Pinterest e garantir que os produtos sejam publicados corretamente e de forma consistente. Além disso, a notificação de publicação para o time de marketing ajudará a garantir que todos estejam informados sobre as publicações de produtos.
