# THEO · Tarefa Full Throttle

**Briefing:** Auditoria técnica diária Shopify: pixel, velocidade, produtos sem foto, links quebrados. Liste top 3 itens para corrigir hoje.

---

Com base nos dados atuais da loja Aura Decore, aqui estão os top 3 itens para corrigir hoje na auditoria técnica diária Shopify:

1. **Produtos sem foto**: Verifique os produtos sem imagem no catálogo da loja. Utilize a API do Shopify para obter a lista de produtos sem foto e priorize a adição de imagens de alta qualidade para esses produtos. Isso ajudará a melhorar a experiência do usuário e aumentar as taxas de conversão.

2. **Velocidade da loja**: Verifique a velocidade da loja utilizando ferramentas como o PageSpeed Insights ou o GTmetrix. Identifique os principais gargalos de desempenho e aplique otimizações para melhorar a velocidade de carregamento da loja. Isso pode incluir a compressão de imagens, a minimização de arquivos CSS e JS, e a otimização de recursos.

3. **Links quebrados**: Utilize ferramentas como o Ahrefs ou o SEMrush para identificar links quebrados na loja. Corrija esses links para evitar erros 404 e melhorar a experiência do usuário. Além disso, verifique se os links internos estão funcionando corretamente e se os links externos estão sendo abertos em uma nova aba.

Esses itens devem ser priorizados para garantir que a loja Aura Decore esteja funcionando corretamente e oferecendo uma experiência de usuário de alta qualidade.
