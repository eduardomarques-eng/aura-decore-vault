**1. Tema Visual:**
O conceito central para a maratona de fim de semana é "Serenidade em Casa". Este tema busca transmitir a ideia de criar ambientes internos que promovam a calma, o equilíbrio e a conexão com a natureza.

**2. Paleta Expandida:**
A paleta de cores para esta campanha é baseada nas cores principais da Aura Decore, com a adição de dois acentos para dar mais profundidade e interesse visual.

- **Cores Principais:**
  - Terracota: #B8793A
  - Off-White: #F5F0EB
  - Sage: #8BA888
- **Acentos:**
  - Um tom mais escuro de verde, para adicionar profundidade: #4E5338
  - Um tom suave de bege, para trazer calor: #C9C4B5

**3. Diretrizes Fotográficas:**
Para manter a consistência visual, as fotografias devem seguir estas diretrizes:
- **Ângulos:** Use ângulos naturais e suaves, evitando perspectivas extremas.
- **Iluminação:** Priorize a luz natural, mas use iluminação suave e indireta quando necessário, para criar uma atmosfera acolhedora.
- **Props:** Incorporar elementos naturais como plantas, madeira e pedras para reforçar o tema de serenidade.
- **Estilo:** Prefira o estilo flat lay para produtos e detalhes, e use perspectivas para mostrar espaços e ambientes.
