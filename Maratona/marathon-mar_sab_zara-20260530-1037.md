# ZARA · Community building — DMs, influencers, engajamento

**Estratégia de Community Building para a Aura Decore**

**1. DM de Boas-Vindas**

* Mensagem calorosa: "Bem-vindo à comunidade da Aura Decore! Estamos aqui para ajudar você a criar um espaço elegante e autêntico. Oferecemos descontos exclusivos para nossos novos seguidores. Use AURA15 para receber 15% de desconto em sua próxima compra!"
* Objetivo: criar uma impressão positiva e encorajar a compra.

**2. Template de Resposta para Comentários**

* a) Elogio ao produto:
 + "Muito obrigada por sua gentileza! Nossa equipe trabalha arduamente para criar produtos de alta qualidade. Se precisar de mais ajuda, não hesite em perguntar!"
* b) Pergunta sobre preço/frete:
 + "Entendemos que o preço pode ser um fator importante. Nossa política de frete é gratuita para compras acima de R$ [X]. Se precisar de mais informações, basta perguntar!"
* c) Pedindo indicação de produto:
 + "Agradecemos por sua preferência! Se precisar de ajuda para escolher o produto certo, nossa equipe de suporte está aqui para ajudar. Qual é o seu estilo favorito?"
