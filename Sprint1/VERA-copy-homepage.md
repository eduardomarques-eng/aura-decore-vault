## 11. PÁGINA "SOBRE A AURA DECORE"

**Headline:**
```
Uma marca que acredita no espaço como extensão de quem você é.
```

**Manifesto (3 parágrafos):**
```
Aura Decore nasceu da convicção de que um objeto bem escolhido 
muda a atmosfera de um ambiente — e, por extensão, de quem vive nele.

Trabalhamos com uma curadoria rigorosa: só entra o que passa pelo 
filtro do tempo. Peças que continuarão fazendo sentido daqui a dez anos.

Japandi não é apenas um estilo. É uma postura: menos ornamento, 
mais presença. Silêncio como elemento de design.
```
