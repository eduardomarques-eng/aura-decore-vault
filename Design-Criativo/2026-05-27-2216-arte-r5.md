**Guia de Estilo Visual Definitivo Aura Decore**

**Paleta de Cores:**

* **Terra**: #B8793A (cor principal)
* **Off-White**: #F5F0EB (cor secundária)
* **Sand**: #F2F2F2 (cor de fundo neutra)

**Fontes:**

* **Cormorant**: fonte serif para títulos e subtítulos importantes
* **DM Sans**: fonte sans-serif para texto corpo

**Regras de Composição:**

1. **Balanceamento**: sempre balancear elementos visuais na composição para criar uma sensação de harmonia.
2. **Contraste**: usar contraste de cores e formas para chamar atenção e criar interesse.
3. **Simplesidade**: manter a composição simples e minimalista, evitando excesso de informações.
4. **Foco**: sempre deixar um elemento centralizado e destacado na composição.

**Regras de Uso:**

1. **Cor principal**: usar a cor terra (#B8793A) como cor principal para todas as comunicações visuais da Aura Decore.
2. **Cor secundária**: usar a cor off-white (#F5F0EB) como cor secundária para elementos de destaque, como títulos e subtítulos.
3. **Cor de fundo**: usar a cor sand (#F2F2F2) como cor de fundo para todas as imagens e elementos visuais.
4. **Tipografia**: usar a fonte Cormorant para títulos e subtítulos importantes, e a fonte DM Sans para texto corpo.

**O que não fazer:**

1. **Não usar cores vibrantes**: evitar usar cores vibrantes e fortes que possam distrair do conteúdo principal.
2. **Não usar fontes desconhecidas**: evitar usar fontes desconhecidas ou que não sejam parte do guia de estilo visual da Aura Decore.
3. **Não exagerar no uso de elementos**: evitar exagerar no uso de elementos visuais, como imagens e ícones, para não criar uma composição confusa.
4. **Não esquecer a simplicidade**: nunca esquecer a simplicidade e a minimalidade que caracterizam o estilo visual da Aura Decore.

**Especificações de uso:**

* **Resolução**: sempre usar imagens com resolução mínima de 1024x768 pixels.
* **Formato**: sempre usar imagens no formato PNG ou JPEG.
* **Tamanho**: sempre usar imagens com tamanho máximo de 2MB.
