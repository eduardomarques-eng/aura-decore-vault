# Skill: Kaizen (Loop Engineering + Melhoria Contínua)

## Objetivo
Habilidade reutilizável de melhoria contínua. O coração do sistema Aura Decore.

## Loop Engineering
```
PLAN → BUILD → MEASURE → LEARN → OPTIMIZE → (PLAN)
 ↑________________________________________________↓
```
- Ciclo semanal: início segunda 09h (VEGA)
- Auditoria Kaizen: segunda 10h (ECHO)
- Mínimo: 1 melhoria implementada por ciclo

## Priorização (impacto × risco × esforço)
```
Prioridade = (Impacto + Risco) × (6 − Esforço)
```
- Impacto: quanto acelera o resultado (1-5)
- Risco: o que acontece se não fizer (1-5)
- Esforço: dificuldade da correção (1-5, invertido)

## Template de Kaizen
```
🎯 Problema: [o que está ruim/lento]
🔍 Causa raiz: [5 porquês]
🛠️ Ação: [melhoria proposta]
📊 Métrica de sucesso: [como saber que funcionou]
📅 Prazo: [quando]
👤 Responsável: [agente]
```

## Ferramentas Kaizen
- **5 Porquês** — causa raiz
- **PDCA** — Plan-Do-Check-Act
- **Eliminação de desperdício** (muda): retrabalho, espera, superprodução de conteúdo
- **Padronização** — todo ganho vira regra em `@rules.md`
