# Skill: Copywriting (PT-BR Magnético)

## Objetivo
Habilidade reutilizável de escrita persuasiva PT-BR para a Aura Decore.

## Princípios
- **Sempre PT-BR.** Tom caloroso e sofisticado.
- Alternar **profissional** ↔ **humanizado** a cada post.
- Benefício sensorial > especificação técnica (calma, aconchego, ordem, identidade).
- Persona: Ana Clara (ver `@memory/persona-ana-clara.md`).

## Frameworks
| Framework | Quando usar |
|-----------|-------------|
| AIDA | anúncios pagos |
| PAS (Problema-Agitação-Solução) | low ticket |
| Storytelling | conteúdo humanizado |
| 4U (Útil, Urgente, Único, Ultra-específico) | headlines |

## Gatilhos Neuromarketing
- Pertencimento ("um lar que respira você")
- Transformação ("do caos à calma")
- Autocuidado ("seu refúgio merece")
- Prova social, antecipação, reciprocidade

## Estrutura de Caption (obrigatória)
```
[GANCHO emocional/curioso]
[CORPO: benefício + história/dica]
[CTA claro]
auradecore.com.br
```
