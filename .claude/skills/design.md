# Skill: Design Visual (Japandi)

## Objetivo
Habilidade reutilizável de criação visual coerente com a identidade Aura Decore.

## Identidade Japandi
- **Paleta**: off-white, bege linho, madeira clara (carvalho), verde seco, cinza pedra, preto suave (acentos)
- **Texturas**: linho, madeira natural, cerâmica fosca, rattan, algodão
- **Luz**: natural difusa, sombras suaves, atmosfera serena
- **Composição**: minimalista, espaço negativo, equilíbrio assimétrico
- **PROIBIDO**: cores saturadas, fundo branco puro, brilho artificial, clutter

## Prompt Pollinations (base reutilizável)
```
japandi [PRODUTO/CENA], neutral earthy palette, light oak wood, linen and
ceramic textures, off-white walls, dried botanicals, soft diffused natural
light, minimalist composition, negative space, serene cozy mood, photographic, high detail
```
