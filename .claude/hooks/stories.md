# Hook: Estrutura de Stories

## Objetivo
Template e sequências prontas para Stories (Instagram/Facebook).

## Sequência Padrão (3-5 stories)
```
1. GANCHO     → enquete/pergunta/curiosidade
2. CONTEXTO   → bastidor/produto/dica
3. VALOR      → demonstração/transformação
4. PROVA      → depoimento/UGC (opcional)
5. CTA        → "Arrasta pra cima" / link auradecore.com.br
```

## Elementos Interativos
- Enquete ("Qual você prefere? A ou B")
- Caixa de perguntas ("Me conta seu maior desafio na decoração")
- Quiz ("Qual estilo combina com você?")
- Contagem regressiva (lançamento/oferta)
