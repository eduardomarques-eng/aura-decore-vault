# Hook: Estrutura de Pinterest

## Objetivo
Template para pins otimizados (SEO visual de longo prazo).

## Anatomia do Pin
```
TÍTULO (rico em keyword PT-BR, até 100 caracteres)
DESCRIÇÃO (200-500 caracteres, keywords naturais + CTA)
LINK → produto/coleção em auradecore.com.br
BOARD → temático (ex: "Decoração Japandi", "Sala Minimalista")
```

## Formato Visual
- **Vertical 1000×1500** (2:3) — ideal Pinterest
- Texto overlay legível (título do conteúdo)
- Estilo Japandi (ver `@skills/design.md`)

## Banco de Títulos (PT-BR + SEO)
- "Decoração Japandi: 5 ideias para sala minimalista e aconchegante"
- "Como criar um lar calmo com estilo japonês e escandinavo"
- "Ideias de decoração natural para quarto Japandi"
- "Antes e depois: transformação Japandi de ambiente pequeno"

## Boards Recomendados
- Decoração Japandi
- Sala Minimalista
- Quarto Aconchegante
- Cozinha Natural
- Antes e Depois
