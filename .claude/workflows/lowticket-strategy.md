# Workflow: Estratégia Low Ticket

## Objetivo
Operar o Motor Low Ticket: do bundle à primeira venda e recompra.

## Gatilho
Contínuo + auditoria mensal (28/06/2026 próxima).

## Fluxo
```
VERA define oferta/bundle (TOP 5 SKUs)
   → LENA escreve copy de venda (PAS)
      → IVE gera criativos do bundle
         → LUNA programa no calendário
            → Eduardo publica
               → MIRA mede conversão
                  → VEGA decide ajuste
                     → ECHO Kaizen mensal
```
