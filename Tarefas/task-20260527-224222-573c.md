## Resultado
Aqui estão os 3 snippets CSS/Liquid para melhorar a UX do Shopify:

**1. Botão Comprar Mobile com Animação Japandi**

Em `layout/theme.liquid`, adicione o seguinte código antes do `{{ content }}`:
```liquid
<div class="mobile-button-container">
  <button class="mobile-buy-button" data-aos="fade-right" data-aos-duration="800">
    <span>Comprar</span>
  </button>
</div>
```
Em `styles.css`, adicione o seguinte código:
```css
.mobile-button-container {
  margin-top: 20px;
}

.mobile-buy-button {
  background-color: #333;
  color: #fff;
  border: none;
  padding: 10px 20px;
  font-size: 16px;
  cursor: pointer;
  transition: all 0.3s ease;
}

.mobile-buy-button:hover {
  background-color: #555;
}

.mobile-buy-button[data-aos] {
  animation-fill-mode: both;
}

@keyframes fade-in-right {
  0% {
    transform: translateX(-100px);
    opacity: 0;
  }
  100% {
    transform: translateX(0);
    opacity: 1;
  }
}

.mobile-buy-button[data-aos="fade-right"] {
  animation: fade-in-right 0.8s ease;
}
```
Essa animação japandi cria um efeito de fade-in à direita, dando uma sensação de movimento suave.

**2. Banner de Urgência Minimalista Terra/Off-White**

Em `layout/theme.liquid`, adicione o seguinte código antes do `{{ content }}`:
```liquid
<div class="urgent-banner">
  <div class="container">
    <h2>{{ 'banner.urgency' | t }}</h2>
    <p>{{ 'banner.description' | t }}</p>
    <button class="call-to-action">Clique aqui</button>
  </div>
</div>
```
Em `settings_data.json`, adicione o seguinte código:
```json
{
  "banner": {
    "urgency": "Oferta Limitada!",
    "description": "Não perca essa oportunidade! Compre agora e receba [desconto] de desconto!"
  }
}
```
Em `styles.css`, adicione o seguinte código:
```css
.urgent-banner {
  background-color: #964B00; /* cor terra */
  color: #fff;
  padding: 20px;
  text-align: center;
}

.urgent-banner .container {
  max-width: 800px;
  margin: 0 auto;
}

.urgent-banner h2 {
  font-size: 24px;
  font-weight: bold;
}

.urgent-banner p {
  font-size: 18px;
  color: #ccc;
}

.call-to-action {
  background-color: #333;
  color: #fff;
  border: none;
  padding: 10px 20px;
  font-size: 16px;
  cursor: pointer;
  transition: all 0.3s ease;
}

.call-to-action:hover {
  background-color: #555;
}
```
Essa banner de urgência minimalista tem um design simples e eficaz, destacando a oferta limitada e incentivando o usuário a clicar.
