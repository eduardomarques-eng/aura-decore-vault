## Resultado
Aqui estão os passos técnicos para auditoria da loja Aura Decore em relação a PageSpeed e Core Web Vitals:

**PageSpeed**

1. **Verificar o score de PageSpeed**:
 - Acesse o Google PageSpeed Insights (https://developers.google.com/speed/pagespeed/insights) e insira o URL da loja (https://auradecore.com.br).
 - Verifique o score de PageSpeed para Mobile e Desktop.
2. **Identificar problemas de carregamento de recursos**:
 - Verifique se há recursos que não estão sendo carregados adequadamente, como imagens, JavaScripts e CSS.
 - Use ferramentas como Lighthouse ou WebPageTest para identificar problemas de carregamento de recursos.
3. **Optimizar imagens**:
 - Verifique se as imagens estão sendo otimizados para carregamento rápido.
 - Use ferramentas como TinyPNG ou ImageOptim para otimizar as imagens.
4. **Minificar e combinar arquivos CSS e JavaScript**:
 - Verifique se os arquivos CSS e JavaScript estão sendo minificados e combinados.
 - Use ferramentas como Gzip ou Brotli para minificar e combinar arquivos.
5. **Usar cache**:
 - Verifique se o cache está configurado corretamente para reduzir o carregamento de recursos.
 - Use ferramentas como Redis ou Memcached para melhorar o cache.

**Core Web Vitals**

1. **Verificar o score de LCP (Large Contentful Paint)**:
 - Acesse o Google PageSpeed Insights e insira o URL da loja (https://auradecore.com.br).
 - Verifique o score de LCP para Mobile e Desktop.
2. **Verificar o score de FID (First Input Delay)**:
 - Acesse o Google PageSpeed Insights e insira o URL da loja (https://auradecore.com.br).
 - Verifique o score de FID para Mobile e Desktop.
3. **Verificar o score de CLS (Cumulative Layout Shift)**:
 - Acesse o Google PageSpeed Insights e insira o URL da loja (https://auradecore.com.br).
 - Verifique o score de CLS para Mobile e Desktop.
4. **Identificar problemas de layout e renderização**:
 - Verifique se há problemas de layout e renderização que estão afetando a experiência do usuário.
 - Use ferramentas como Lighthouse ou WebPageTest para identificar problemas de layout e renderização.
5. **Melhorar a experiência do usuário**:
 - Verifique se a experiência do usuário está sendo afetada por problemas de layout e renderização.
 - Use ferramentas como UserTesting ou TryMyUI para coletar feedback do usuário e melhorar a experiência.
